# Suggestions/Bugs
If you want to suggest a change/report a bug, just create a new issue.

# Pull Requests
If you want to change something:
- fork this repo
- create a new branch. Name should look like this: `<what type of change you make>/<topic of change>`. for example: `fix/cursor-blinking`
- make your changes
- commit your changes. please refer to [conventional commits](https://www.conventionalcommits.org/en/v1.0.0/#summary) when commenting on them. TLDR: name them in the style `fix/chore/feat/refactor: what you changed`
- push them
- create a pull request
- if the test are failing, don't panic! just fix any issues and push again

Have fun :)
